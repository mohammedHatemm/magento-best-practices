## 🛠️ Tools & Commands

### Development Commands

```bash
# Enable module
php bin/magento module:enable Elsherif_LoyaltySystem

# Run setup
php bin/magento setup:upgrade

# Compile DI
php bin/magento setup:di:compile

# Deploy static content
php bin/magento setup:static-content:deploy -f

# Clear cache
php bin/magento cache:flush

# Add points (CLI)
php bin/magento loyalty:points:add 1 100

# Run cron manually
php bin/magento cron:run
```

### Debugging Commands

```bash
# Check module status
php bin/magento module:status Elsherif_LoyaltySystem

# Verify tables
mysql> SHOW TABLES LIKE 'elsherif_%';

# Check logs
tail -f var/log/loyalty_system.log
tail -f var/log/system.log

# Test REST API
curl -X GET "https://site.com/rest/V1/loyalty/balance/1" -H "Authorization: Bearer {token}"

# Test GraphQL
# Use GraphQL Playground at: https://site.com/graphql
```
